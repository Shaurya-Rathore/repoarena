# Changelog

## 1.0.0 — 2026-09-07

- Replay real historical bugs against Codex, Claude Code, Gemini CLI, and
  OpenCode with local-first BYOK execution.
- Deterministic execution, hidden verification, terminal/JSON/HTML/JUnit
  reports, readiness analysis, local UI, and configuration optimizer.
- Production local and cloud products with comparison, explicit publishing,
  leaderboard, share pages, and badges.
- PostgreSQL control plane with RBAC, jobs, runners, schedules, API keys,
  audit events, usage, and object storage.
- GitHub App, Checks, fork-safe triggers, bundled Action, and Actions OIDC.
- Stripe subscriptions mapped into provider-independent entitlements; model
  usage remains BYOK.
- Optional hosted compute with ephemeral credentials, transactional capacity,
  immutable metering, cancellation, and orphan reconciliation.
